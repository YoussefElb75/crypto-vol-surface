# Data: sources, conventions and terms of use

## Source

All market data comes from **Deribit's public JSON-RPC API v2** (`https://www.deribit.com/api/v2`),
over plain HTTP GET. Only unauthenticated `public/*` methods are called. The client
(`src/cryptovol/deribit.py`) refuses any other method, and there are no API keys and no trading.

| Method | Used for |
|---|---|
| `public/get_instruments` (`kind=option` / `future`) | strike, option type, expiry timestamp |
| `public/get_book_summary_by_currency` (`kind=option` / `future`) | best bid / ask, mark price, mark IV, underlying price, open interest, volume |
| `public/get_index_price` (`btc_usd`, `eth_usd`) | spot index |
| `public/get_order_book` | optional; per-instrument `bid_iv` / `ask_iv` (not used by the pipeline) |

A full BTC + ETH snapshot needs 10 requests. The client waits at least 0.25 s between
requests, which keeps it far below Deribit's credit-based rate limits for public methods.

## Conventions, checked on live data

* **Prices are in coin.** Option bid, ask and mark prices are quoted in BTC (or ETH) per option on
  one coin. The pipeline converts them to USD with the forward: $`V_{USD} = V_{coin}\,F`$.
* **Mark price model.** The Deribit coin mark price equals the Black-76 price at `mark_iv`, at the
  option's `underlying_price` and with a zero rate, divided by `underlying_price`, up to rounding.
  So $`df = 1`$ is used throughout.
* **Mark IV** is quoted in percent; the pipeline stores decimals.
* **Expiry** is 08:00 UTC; year fractions are ACT/365 measured in milliseconds.
* **Delta.** The `greeks.delta` returned by `public/ticker` is the plain Black-76 forward delta
  $`N(d_1)`$ (not premium-adjusted), up to rounding. This is why the forward delta is the default
  25-delta convention (see README).
* **Futures** exist for every listed option expiry, so forwards come from the futures mid.
  Put-call parity on coin prices, $`(C-P)_{coin} = 1 - K/F`$, is the fallback.

These conventions were checked once against live responses, for personal use; no live values are
reproduced here.

## Snapshot format

`scripts/refresh_snapshots.py` writes `data/snapshots/<YYYY-MM-DDTHHMMSSZ>/` with
`options.parquet`, `futures.parquet` and `meta.json`. The columns are listed in
`src/cryptovol/snapshots.py`.

## Terms of use, and what this repository publishes

Deribit's Terms of Service (clause 4.6, introduced in the
[29 January 2021 update](https://insights.deribit.com/exchange-updates/deribit-updates-terms-of-service-as-of-29-january-2021/))
state:

> The use of Market Data and/or Derived Data is for personal use only. You are not allowed to
> aggregate, resell, publish, forward or in any other way process Market Data and/or Derived Data
> (except for personal use) without explicit approval from us.

The same restriction is reported in clause 2.10 of the Deribit FZE Exchange Membership Terms
(version of 26 January 2026). Check the current
[Terms of Service](https://www.deribit.com/pages/information/terms-of-service) yourself before you
use the data: when this was written, the live pages could not be fetched automatically.

What this means for this repository:

* **No Deribit data, and nothing derived from it, is committed.** Every published figure
  (`docs/figures/`), every number in the README and the demo notebook's saved outputs come from a
  **synthetic** snapshot (`tests/fixtures/synthetic/`). It has Deribit's schema, tick size and
  quoting conventions, is generated by `scripts/make_synthetic_fixture.py` from a known SSVI
  surface, and never touches the network. Each published figure says "synthetic data" in its
  footer.
* **Tests and CI use only the synthetic snapshot.**
* **Live data stays on your machine.** `data/snapshots/` (raw snapshots), `data/local/` (figures
  built from them) and `data/derived/` (tables) are git-ignored.

To reproduce the analysis on live data, for your own personal use:

```bash
python scripts/refresh_snapshots.py    # 10 public requests -> data/snapshots/<stamp>/
python scripts/make_figures.py         # -> data/local/figures/ and data/derived/live/
```

The demo notebook uses the latest live snapshot when there is one; clear its outputs before you
commit, or set `CRYPTOVOL_SYNTHETIC=1` to force the synthetic fixture. Do not publish or
redistribute anything built from live data without Deribit's explicit approval.
`python scripts/make_figures.py --synthetic` rebuilds the published figures.

Nothing in this repository is affiliated with or endorsed by Deribit.
